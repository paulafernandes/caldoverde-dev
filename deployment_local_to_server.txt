DEPLOY

1. No teu PC, entrar na pasta do projeto

cd ~/projects/caldoverde/react-files

2. Copiar os ficheiros para o VPS

rsync -av --delete \
  --exclude node_modules \
  --exclude .next \
  ./ \
  miguel@87.106.236.149:/home/miguel/caldoverde/

3. Entrar no VPS

ssh miguel@87.106.236.149

4. Entrar na pasta do projeto

cd ~/caldoverde

5. Instalar/atualizar dependências

npm install

6. Fazer o novo build

npm run build

7. Reiniciar o site

sudo systemctl restart caldoverde

8. Confirmar que está a funcionar

sudo systemctl status caldoverde

e testar http://87.106.236.149 no browser.

Resumo para guardares:

PC:
rsync → ssh

VPS:
cd ~/caldoverde
npm install
npm run build
sudo systemctl restart caldoverde
